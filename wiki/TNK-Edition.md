# TNK edition — 1.0.2

**Minecraft 1.21.1 · NeoForge 21.1.262 · Java 21.** Install one matching `tnkloot` JAR on clients and server, plus the real TNK Progression companion and the required Apotheosis dependencies.

The current branch records checks with Progression 1.2.0-private.1 and 1.3.0-private.1, Apotheosis 8.9.0, Apothic Attributes 2.11.0, Placebo 9.9.4 and Patchouli 1.21.1-93-NEOFORGE. Optional Create integration was checked with Create 6.0.10 and Ponder 1.0.82. Use the exact dependency set supplied with your pack.

## Identify, salvage and discover

Bring sealed rewards to an Identifier and insert up to seven items. Review the displayed XP cost and confirm the batch. The TNK edition also includes salvage, reward previews, a collection journal, boss groups and operator editing. Its Common, Uncommon, Rare, Epic, Legendary and Mythic equipment groups share tier-bounded affixes with Apotheosis.

Mob/source levels and Progression milestones limit the available rarity. Previously earned sealed drops retain their recorded data; trading one does not upgrade its source level. Acquired equipment can appear in discoveries without inflating identification counts.

## Automation

The optional Create **Mechanical Identifier** automates identification using its Liquid XP supply. Follow the in-game Ponder lessons for the station, item and XP paths. Keep Create and the matching Enchantment Industry version from the pack together.

## Operators

Use `/tnkloot reload` after supported configuration changes and `/tnkloot audit` to export runtime groups, attributes, affixes, source levels and boss mappings into `config/tnkloot/reports`.
